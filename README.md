# Risk Radar – Global Security

A daily, AI-assisted assessment of global and national security risks over a 12-month horizon, based on open sources.

- `index.html` – the page (static, no build step)
- `data/snapshots/YYYY-MM-DD.json` – one analysis per day
- `data/manifest.json` – list of available snapshots
- `tools/add_snapshot.py` – adds a new snapshot (removes private fields)
